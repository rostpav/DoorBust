# Door Bust

A simple mod that allows you to bust open doors while you running.

## Supported versions

| Loader  | Minecraft |
|---------|-----------|
| Forge   | 1.20.1    |

## Download

Grab the latest jar from the [Releases](https://github.com/rostpav/DoorBust/releases) page and drop it into your `mods` folder.

## Building

Requires JDK 17. From the project root:

```powershell
.\gradlew.bat clean build
```

The resulting jar will be in `build/libs/`.
